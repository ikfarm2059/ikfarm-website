プライバシーポリシー

株式会社アイケーファーム　制定日：2026年10月16日

株式会社アイケーファーム(以下「当社」)は、当社のホームページ、SNSでの発信、および当社が業務のために作成・運用しているソフトウェア(以下「当社のツール」)において取り扱う情報について、以下のとおり定めます。

1. 当社のツールと外部サービスの利用

当社は、当社自身の公式アカウントでの情報発信と、その反応の確認のために、次の外部サービスのAPI(プログラムから利用するための窓口)を利用しています。当社のツールは当社の社内でのみ使用しており、当社以外の方がログインして利用するものではありません。

  • YouTube API サービス(Google LLC 提供):当社の YouTube チャンネルへの動画・サムネイル・字幕の投稿、および当社チャンネルの視聴データ(再生回数、視聴時間、視聴者の年代・性別・地域・流入元などの集計値)の確認に利用しています。
  • Instagram API・Threads API(Meta Platforms, Inc. 提供):当社アカウントへの投稿と、投稿の反応(表示回数・いいね等の集計値)の確認に利用しています。

当社のツールは YouTube API サービスを利用しています。YouTube API サービスの利用にあたっては、次の規約・方針が適用されます。

  • YouTube 利用規約:https://www.youtube.com/t/terms
  • Google プライバシーポリシー:https://policies.google.com/privacy

2. 取得する情報

  • 当社のツールが YouTube・Instagram・Threads から取得するのは、当社自身のアカウントとチャンネルに関する情報(投稿した内容、および再生回数・視聴者の年代や地域などの集計された統計)です。
  • 視聴者の方の氏名、メールアドレス、アカウント名など、個人を特定できる情報は取得していません。統計はサービス側で集計された数値として受け取ります。
  • 当社のホームページでは、お問い合わせの際にいただいたメール・お電話の内容(お名前、連絡先、ご用件)をお預かりします。
  • 採用へのご応募の際には、履歴書などの応募書類に記載された情報(お名前、ご住所、連絡先、経歴など)をお預かりします。

3. 利用目的

  • 当社の事業・農作業の様子をお伝えする情報発信のため
  • 発信がどのような方に届いているかを把握し、内容を改善するため(主な目的は採用活動です)
  • お問い合わせへの回答のため
  • 採用選考、および応募者の方へのご連絡のため

取得した情報を、上記以外の目的で利用することはありません。

4. 情報の保管と第三者への提供

  • 取得した統計情報は、当社の業務用パソコンと、当社が契約するクラウドの保管場所(暗号化して保存)で管理します。
  • 応募書類は採用選考のためだけに使用し、採用に至らなかった場合は、選考の終了から6か月以内に責任をもって処分します。
  • 法令に基づく場合を除き、取得した情報を第三者に販売・提供することはありません。
  • 当社のツールは、閲覧者のブラウザに Cookie(クッキー)を保存したり、閲覧者の端末から情報を読み取ったりすることはありません。

5. 連携の解除・情報の削除

  • 当社のツールと Google アカウントとの連携は、Google のセキュリティ設定ページからいつでも解除できます:https://security.google.com/settings/security/permissions
  • 連携を解除した場合、当社のツールはその後、YouTube API サービスからの情報の取得を行いません。また、連携の解除から30日以内に、YouTube API サービスから取得して保存していた情報を削除します。
  • お預かりした情報の確認・削除をご希望の場合は、下記のお問い合わせ先までご連絡ください。
